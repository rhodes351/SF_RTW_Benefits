Replication materials for "For What Benefit? State Right to Work Laws and Employer-Provided Retirement and Health Insurance Benefits"

In these files, I provide the clean individual-level data used in my analyses. I also provide Stata code to replicate the statistical analyses that inform the core arguments in the article.

-CLEAN_ASEC_DATA_RTW_ANALYSIS.do: A clean .dta file include the individual-level data used in the analyses.

-RTW_analysis_ASEC_only: A .do file including most of the main text analyses.

For questions about these files, please see the published article in Social Forces or contact me (aprhodes@purdue.edu).
